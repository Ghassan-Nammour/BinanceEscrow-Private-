Binance Private escrow
No signup · no accounts · no server. Deal data lives in your browser and inside the link.
Only assets with a saved payout address appear in the list. Set up wallets.
Paste the receiving address for each asset. Saved locally, never transmitted. Only filled slots are offered when creating a deal.
Validation is format-only — always double-check the first and last characters before publishing.
Semi-custodial. No smart contract: funds go straight to the payout wallet and release is executed manually by the escrow agent. The link is the only credential — anyone holding it can read the deal. Confirm addresses out-of-band before sending.
